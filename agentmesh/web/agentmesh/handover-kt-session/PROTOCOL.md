# Handover Kt Session — Serving Contract & SSE Protocol

This SPA talks directly to the **deployed Handover Kt Session agent service** — there is no
separate serving backend to build. The agent service (generated by the deploy
pipeline, or run via `GenericAgentServer`) already exposes this full contract via
`agentzoo.serving.create_serving_router`. Point `AGENT_API_URL` at that service.

## Backend contract (provided by the agent service)

| Method & path | Purpose |
|---|---|
| `POST /invoke/handover-kt-session/stream` | Run the agent, stream progress via SSE |
| `GET /invocations` | Paginated invocation list (dashboard) |
| `GET /invocations/stats` | Dashboard counters |
| `GET /invocations/{id}` | Invocation detail: latest state + timeline |


## Streaming endpoint

```
POST /invoke/handover-kt-session/stream
Content-Type: application/json

{ "input": { ... } }
```

Response: `text/event-stream`

## Event Types

### `node_start`

Emitted when a pipeline node begins execution.

```
event: node_start
data: {"node": "<node_name>", "timestamp": "<ISO 8601>"}
```

### `node_end`

Emitted when a pipeline node completes. Includes the full state snapshot.

```
event: node_end
data: {"node": "<node_name>", "state": {...}, "timestamp": "<ISO 8601>"}
```

The `state` object conforms to the `AgentState` TypeScript interface
in `src/types.ts`.

### `hitl_waiting`

Emitted when the workflow pauses at a HITL gate.

```
event: hitl_waiting
data: {"gate": "<gate_name>", "summary": {...}, "timestamp": "<ISO 8601>"}
```

### `done`

Emitted when the workflow completes successfully.

```
event: done
data: {"state": {...}, "timestamp": "<ISO 8601>"}
```

### `error`

Emitted when an error occurs.

```
event: error
data: {"error": "<message>", "node": "<node_name or null>", "timestamp": "<ISO 8601>"}
```

## REST Endpoints

| Method | Path | Purpose |
|--------|------|---------|
| `GET` | `/invocations` | List recent invocations (dashboard) |
| `GET` | `/invocations/{id}` | Fetch single invocation |
| `GET` | `/invocations/stats` | Dashboard summary counters |
| `POST` | `/invoke/handover-kt-session/stream` | Start invocation (SSE) |
| `POST` | `/approvals/{id}` | Submit HITL decision |

## State Schema

The `AgentState` interface is auto-generated from the YAML definition.
See `src/types.ts` for the full TypeScript interface.

## Error Handling

- The SPA retries failed connections up to 5 times with exponential backoff.
- If the SSE stream disconnects, the SPA falls back to polling
  `GET /invocations/{id}` to recover state.
- All REST endpoints return standard HTTP error codes with JSON error bodies.
